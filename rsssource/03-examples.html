03 四个能直接改的示例

下面每个例子都是完整可导入的。把 sourceUrl 和规则换成你自己的就能用。

① 标准 RSS:两行

{
  "sourceUrl": "https://example.com/feed.xml",
  "sourceName": "某站 RSS"
}

就这样。RSS / Atom 都认,规则一条都不用写。

② 网页列表型:加摘要与正文

{
  "sourceUrl": "https://example.com/blog",
  "sourceName": "某站博客",
  "sortUrl": "最新::https://example.com/blog\n归档::https://example.com/blog/archive",
  "ruleNextPage": "class.pager@class.next@href",
  "ruleArticles": "class.post-list@tag.li",
  "ruleTitle": "tag.h2@text",
  "ruleLink": "tag.h2@tag.a@href",
  "rulePubDate": "class.date@text",
  "ruleImage": "tag.img@src",
  "ruleDescription": "class.excerpt@text",
  "ruleContent": "class.article-body@html"
}

注意 ruleArticles 取的是 li(每一篇),后面几个字段都不带容器。

③ JSON 接口型

{
  "sourceUrl": "https://example.com/api/feed",
  "sourceName": "某站接口",
  "enableJs": true,
  "ruleArticles": "$.data.list[*]",
  "ruleTitle": "$.title",
  "ruleLink": "$.url",
  "rulePubDate": "$.published_at",
  "ruleImage": "$.cover",
  "ruleDescription": "$.summary",
  "ruleNextPage": "PAGE"
}

列表规则用 $.data.list[*],字段规则只写 $.字段名。ruleNextPage 写 PAGE 表示"按 sortUrl 里的 {{page}} 翻页"。

④ 单 url 源:整页当一篇读

{
  "sourceUrl": "https://example.com/daily",
  "sourceName": "每日更新",
  "singleUrl": true,
  "loadWithBaseUrl": true
}

软件会用内置浏览器把这一页整个加载出来当正文 —— 页面自己的脚本照跑,内嵌视频也能播。适合"整站就一个页面"或者"想读的就是这一页"。

给正文配样式

style 字段是正文的 CSS,解析出来的 HTML 会挂在这套样式下渲染:

"style": ".article-body{line-height:1.8;font-size:16px}
          .article-body img{max-width:100%;height:auto}
          .article-body p{margin:10px 0}"

不写就用软件自带的默认样式(图片与视频不溢出、正文有行距)。想改字体、段距、图片圆角,都写在这里。

导进去之后

  • 订阅页顶部是分类条(来自 sortUrl);没有分类就直接是列表;
  • 点开一篇:有 ruleContent 就在软件内解析,没有就打开原网页;
  • 列表拉不到内容时,先在浏览器里打开 sourceUrl 看一眼返回的到底是什么 —— 这是最快的一步。
