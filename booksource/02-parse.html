02 解析:CSS、@Json 与 @js

同一条规则有三种写法。选错不会报错,只会"取到空" —— 而空值在界面上看起来和"这个源没有数据"一模一样,所以先看清返回的是 HTML 还是 JSON。

第一步:返回的是网页还是 JSON

打开调试页看原始响应。以 < 开头的基本是 HTML;以 { 或 [ 开头的是 JSON。两者的规则完全不同,别混用。

HTML:CSS 选择器

  • class.名字 —— 按 class 取;
  • id.名字 —— 按 id 取;
  • tag.标签 —— 按标签取;
  • text.一段文字 —— 按包含的文字取。

取完节点再取属性:

class.book-list@tag.li@tag.a@href

@text 取文字,@html 取内层 HTML,@href / @src 取属性。@tag.a@href 的意思是"在这个节点里再找 a,取它的 href"。

JSON:JSONPath

$.[*]            → 取整个数组的每一项
$.data.list[*]   → 取嵌套数组
$.title          → 取字段

列表规则用 $.[*],字段规则用 $.字段名。这是最省事的一对,能覆盖绝大多数接口型站点。

要计算就走 @js

规则以 @js: 或 <js>…</js> 开头时,整段当 JavaScript 求值,最后一条产生值的语句就是结果。

@js:result = java.ajax(url); JSON.parse(result).data.map(x => x.title).join('\n')

几个容易踩的点

  • 取不到先看是不是选错容器。列表规则取的是一个"每一项"的容器,不是整个列表。class.book-list@tag.li 和 tag.li 不是一回事。
  • 多个候选用 ||:class.a@text||class.b@text 取第一个有结果的。
  • 列表倒序加 - 前缀:-class.list@tag.li。
  • 相对地址不用自己拼。链接会按来源页地址自动绝对化;只有确实需要换域名时才在 @js 里处理。
