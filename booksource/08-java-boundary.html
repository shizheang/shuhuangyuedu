08 方法与边界

java.* 是一张白名单:手册里没有的名字,调用会当场抛错(不是静默返回空)。所以"用了却取到 undefined"这种排查思路在这里不成立 —— 报错就是没实现。

网络

方法说明
java.ajax(url)发一次请求,返回响应正文;URL 后面同样能跟 ,{...} 选项
java.ajaxAll([url1, url2])并发发多次,返回响应数组(取正文用 .body())
java.get(url, headers) / post(url, body, headers) / head(url)带请求头的单次请求
java.connect(url)低层连接(兼容用)
java.importScript(url)拉一段远程 JS 并执行(远程库就这么用)
java.cacheFile(url)下载并缓存一个文件,返回本地相对路径
java.webView(url)用内置浏览器加载(要跑站点自己的 JS 时)
java.startBrowser(url) / startBrowserAwait(url)同上,后者等页面结束再返回
java.open(url) / openUrl(url, mime)交给系统打开(跳转 App / 浏览器)

解析

java.getString(rule)用一条规则在当前内容上取值
java.getStringList(rule)取值列表
java.getElements(rule)取节点列表
java.setContent(html)替换"即将返回的内容" —— 正文 @js 里做二次加工时用

带 Sync 后缀(getStringSync / getElementsSync)的是同一件事的同步版,只在必须同步的上下文里用。

登录与 cookie

java.getLoginInfo(key) / getLoginInfoMap()读本源自己存的登录信息
java.putLoginInfo(key, value) / upLoginData(key, value)写回本源自己的登录信息
java.getLoginHeader() / getLoginHeaderMap()登录时站点回的那组请求头
java.getCookie(url, key) / setCookie / replaceCookie本源自己的 cookie 夹
java.getWebCookie(url) / setWebCookie内置浏览器里的 cookie

变量与身份

java.get(key) / java.put(key, value)源自己的变量表(可落盘,跨章节保留)
java.getTag() / java.getSource()当前请求标签 / 本源地址
java.getUserAgent() / getWebViewUA本机 UA
java.randomUUID()随机 UUID

文本与时间

java.htmlFormat(s)HTML 整理
java.timeFormat(t) / timeFormatUTC(t)时间戳 → yyyy/MM/dd HH:mm,或从一个时间字符串里解析
java.s2t(s) / java.t2s(s)简繁互转
java.toNumChapter(s)中文数字章节号 → 数字
java.toURL(s)相对地址 → 绝对地址

界面与交互

java.toast(msg) / longToast(msg) / log(msg)提示与日志(log 进调试页)
java.setClipboard(text) / copyText(text)复制到剪贴板
java.getVerificationCode(...)要用户输入一次校验码并返回
java.refreshBookToc() / refreshContent() / refreshBookInfo()让宿主重新取一次对应的那一段

源脚本碰得到什么、碰不到什么

  • 能出网 —— 任何域都可以(取数据、取脚本都不问)。但环回、局域网、云元数据地址一律拒:不能拿本软件当跳板去打内网。
  • 能用本源自己的凭据。别的源的账号密码 / cookie 拿不到;真要借用,第一次会问用户一次,结果记在「设置 → 网络设置 → 访问」。
  • 能读写本源自己的变量(java.put / java.get),跨章节、跨重启都在。
  • 碰不到界面:改不了主题、跳不了页面、点不了按钮(除了上面那几个明确开放的动作,比如复制到剪贴板)。
  • 碰不到别的源的数据 —— 变量、登录信息、cookie 都是按源隔离的。

写源时记住一条:规则是在一个**隔出来的环境**里跑的。手册没写的能力就是没有,不要靠"试试看"去猜。
